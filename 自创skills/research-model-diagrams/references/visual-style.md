# 视觉与语言规范

这些是用户在本次迭代中确认的默认偏好，用于同类科研模型图；当次提供的新参考图、字体或出版要求优先。

## 版式：让主干与改动一眼可分

- 白底、二维平面图；模块用浅色矩形或轻微圆角，原模型风格需要时编码器可用梯形。
- 根据下方拓扑选择主方向；同一层级的路径保持一致。标题克制，框架主体占主要面积。
- 路径用浅色虚线框分组。新增模块用浅珊瑚底和较明显的边界；内部小节点仍以中性色表示算子。
- 同类节点对齐、间距稳定；箭头采用水平／垂直折线，尽量避免跨越文字和穿过无关模块。
- 分支较多时使用带名称的来源端口，如 `V`、`T`、`B`，并说明同名端口表示张量复用。不要画一根混合总线使读者以为视觉和文本先合并。
- 总图优先解释输入、主路径、插入点与输出。细节过密时增加局部放大子图，不持续缩小字体。

### 三种布局起点

| 拓扑 | 布局 | 走线重点 |
|---|---|---|
| Encoder–Decoder | 两列同向堆叠，输入各自在列首；保留两列间的 Memory 通道 | 残差走各自模块侧边，Memory 接每层 cross-attention 的 K/V；不能与目标输入共用总线 |
| 并联融合 | 输入／编码器在左，分支按行对齐，融合在右 | 分叉点可见，各分支终点接对应融合端口；长线预留在泳道间 |
| 主干 + 辅助模块 | 主干保持直线，辅助模块放一侧，局部展开放另一侧或另图 | 支路从实际读取位置引出，在真实融合位置回接；展开引导线与计算箭头区分 |

同列模块采用共同中心线和宽度基准；模块内留白、层间距、分区间距按小／中／大三级组织。长标签先语义换行，再调整节点尺寸，不单独缩小到明显低于同级字体。优先压缩无信息的大块留白，保留连接通道；不要为了填满画布添加装饰。

分叉用可见连接点；无连接的交叉避免放点，必要时绕线。残差属于计算流，通常用细实线；虚线优先用于分区边界或明确标注的可选路径。同一种线型的含义在图内固定。主路径稍粗于辅助路径，但两者在最终尺寸都应清晰。

## 配色语义

| 用途 | 推荐色 | 表达 |
|---|---|---|
| 视觉编码器、视觉 Token | 蓝色 `#3587BC`，浅底 `#E5F3FC` | 视觉来源 |
| 文本编码器、文本 Token | 绿色 `#609643`，浅底 `#EEF6E8` | 文本来源 |
| 原有处理模块 | 浅黄 `#FFF4D8`，边框 `#C6A04C` | 已有算子／分类器 |
| 新增模块 | 珊瑚 `#D96757`，浅底 `#FFF0EC` | 本次接入的功能 |
| 字体、通用箭头 | 深灰蓝 `#283646` | 正文和计算流 |
| 路径分区 | 浅底 `#FCFDFF`，虚线 `#85B5D4` | 路径边界 |

颜色用于标明角色，而非声明原创性。新增到本模型的借鉴模块同样可以高亮，但要写清来源或适配属性。不要只靠颜色区分新增／已有，配合模块名、边界和图例。

上表是多模态案例的配色起点。普通 Transformer 等无视觉／文本区分的模型，可将蓝／绿改用于 Encoder／Decoder，并在图例重新定义。保持少量语义色，同类算子同色；用灰度预览确认没有仅靠颜色才能读懂的关系。

## Token 与表示图形

下表用于总图中的简要图标。用户要求展示表示变化时，按 [张量与表示可视化](tensor-visuals.md) 展开操作前后的方块组合与对应关系。

| 表示 | 推荐画法 | 必须避免的误导 |
|---|---|---|
| 视觉序列 | 蓝色小方块，帧数沿另一维排列 | 不把每个方块同时解释成帧和通道 |
| CLS | 与视觉 Token 同色系的深色块 | 不用文本绿色标 CLS |
| 文本序列 | 绿色小方块，EOS 用深绿 | 不把特殊／填充 Token 当成有效词参与平均 |
| 通道分组 | 同一组 patch 特征按通道切分的色块 | 不声称是直接读取 Transformer attention heads |
| patch–word 相似度 | 矩形网格，标 `P × M` | 不画成第二个编码器或新的预测路径 |
| BDC 表示 | 矩阵网格与半向量化小条带 | 不把向量化写成另一种学习算法 |
| 跨组协方差 | 多个一般矩阵网格 | 不默认交叉协方差必然对称 |
| 类别 logits | 短柱条或向量 | 不填入虚构准确率或概率数值 |
| 残差相加 | 圆圈加号与必要的系数 | 两个输入要真实汇合；标明是特征还是 logits 融合，不把所有残差称为 logits 相加 |
| 最终概率融合 | 单独的 Softmax 与加权融合节点 | 不和训练损失混为一谈 |

图标宜放在模块之间的留白，标签放在图标上方或下方。小图标只需表现形态；具体数值、维度和颜色不必仿照随机热力图。

Token 方块仅示意时用省略号和长度符号，避免方块数量暗示固定序列长度。无真实数据时优先用概率向量表达输出；使用柱条或热力图则注明“示意”，不暗示实际预测结果。

## 中文说明、英文算法操作

| 图中内容 | 默认表述 |
|---|---|
| 大标题 | `BDC-CLIP + SMCD + GLTBA 模型框架`，换成实际模型名 |
| 路径标题 | `全局视频-文本对齐`、`视觉分类` |
| 输入、阶段、解释 | `视频帧`、`类别描述`、`默认仅在预训练启用`、`复用同一表示` |
| 标准方法／模型名 | `CLIP Visual Encoder`、`Moment Probing`、`GLTBA` |
| 归一化与相似度 | `Normalize + Dot Product`、`Cosine Similarity` |
| 投影与统计 | `Text Projection`、`Projection + Channel Groups`、`Cross-Group Covariance` |
| 池化与分类 | `Temporal Mean`、`Semantic Head`、`Conv Compression + Moment Head` |
| 聚合与融合 | `MaxSim`、`Mean over valid Word Tokens`、`Weighted Sum`、`Softmax` |
| 图例与符号说明 | 中文解释；变量和标准术语保留英文 |

不要把普通说明整句写成英文；也不必将公认算法名称强行译成不常见中文。长算法名优先按语义断行，保持原有阅读顺序。

## 字体、字号与符号

- 本项目可用 `SimHei`、`WenQuanYi Zen Hei`。其他环境先检查字体，再选支持中文的黑体／宋体；英文字体可用兼容的衬线或无衬线字体。
- 英文论文风格可参考 Times／Liberation Serif；中英混排应保证字高、粗细与间距协调，不因更换字体挤压边框。
- 先确定论文单栏／双栏或演示页面的最终使用宽度，再设字号。按最终尺寸检查，论文标注可从 8–10 pt 起步，具体服从出版要求。不能用高分辨率 PNG 掩盖印刷后文字过小的问题。
- 建立标题、分区、模块、注释四级字号；模块标签优先于辅助说明。论文插图可将大标题移到正文图注中，释放有效空间。
- 维度用精确文本，如 `F × (N + 1) × D`、`L × D`、`P × M`。`L` 是否包含 SOS、EOS、padding，`M` 是否仅有效词，必须按实现解释。
- 若 `T` 用作文本端口，帧数可用 `F`；全图只使用一套约定。数学公式复杂时可用支持公式排版的工具，但不要丢失普通标签的可编辑性。
