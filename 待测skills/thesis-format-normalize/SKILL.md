# 中文毕业论文格式规范化

依据学校的权威模板和本届提交要求，对论文进行可追溯的格式审查；只有用户明确要求修复或规范化时才修改原文档。格式判断必须区分学校硬性要求、模板实例和通用学术建议。

## 必须配合的能力

处理 DOCX 时必须同时使用可用的 Word 文档编辑 Skill，遵守其备份、渲染和逐页视觉检查要求。不要只依据 `python-docx` 的结构数据宣称排版正确。

## 输入与规范优先级

1. 确认唯一权威论文 DOCX；如果目录中存在多个版本，先根据用户指定、修改时间和文件名辨认主文件，不得同时生成多个“最终版”。
2. 优先获取学校本届最终模板、学院通知、答辩或提交要求、签字页和声明页。缺少这些材料时可以按现有模板和通用规范审查，但必须说明无法保证完全符合本届最终提交要求。
3. 按以下优先级解释冲突：本届学校或学院正式要求 > 本届正式模板 > 学校往届正式规范 > 用户指定样例 > 通用国家标准与排版惯例。
4. 区分“完整毕业论文规范”和“优秀论文汇编规范”。包含约 3000 字篇幅要求、汇编版式或摘要式结构的附件不得直接覆盖完整毕业论文。
5. 读取 `references/论文格式审查清单.md`，再结合用户学校材料建立本次审查基线。不要把清单中的常见值误称为学校硬性规定。

## 工作模式

### 仅审查

用户说“检查、看看、是否符合”时，默认只读检查，不修改文件。输出问题、证据位置、依据、严重程度和建议处理方式；无法从现有材料确认的项目标为“待学校规范确认”。

### 规范化修改

只有用户明确说“修复、替换、统一、规范化、插入、更新论文”时才写回 DOCX。修改前把备份放入 Windows 临时目录，只更新用户指定的唯一主文件；中间报告、渲染图和测试文件也放入临时目录或工作区的临时目录，不在论文目录制造版本堆积。

## 审查与修改流程

1. 盘点主文件、学校规范和模板，记录适用范围、发布日期和冲突项。
2. 用 `scripts/audit_thesis_format.py` 生成结构审计 JSON。它用于定位页面、样式、标题、目录、引文、参考文献、图表和直接格式覆盖，不代替人工判断。
3. 检查页面尺寸、页边距、分节、页眉页脚、页码体系、首页差异和节间链接。
4. 检查封面字段、题名、作者、学号、专业、学院、指导教师、日期、声明页及装订顺序是否与权威模板一致。
5. 检查中文字体、英文与数字字体、字号、加粗、对齐、首行缩进、行距、段前段后、分页控制以及标题层级。
6. 检查中英文摘要、关键词、目录域、目录缓存页码和标题映射。目录显示正确不代表字段缓存已更新。
7. 检查图题、表题、公式、编号连续性、正文交叉引用、图片清晰度、表格字体、表头重复、三线表结构和跨页行为。
8. 检查正文引文的方括号、上角标、编号范围、顺序、缺失条目以及未引用文献。对本 Skill 当前适用的论文，正文方括号数字引用必须统一设为上角标；参考文献列表中的条目编号保持普通基线格式。
9. 检查参考文献连续编号、文献类型、作者、题名、期刊或出版社、年份卷期页码、标点、悬挂缩进和 GB/T 7714 一致性；来源真实性无法仅靠排版检查证明，应单独标注。
10. 修改时尽量调整样式而不是逐段堆叠直接格式。保护正文内容、域代码、批注、脚注、尾注、公式、超链接、书签、题注、交叉引用和局部 run 属性。
11. 修改整段文字或重建 run 后，必须重新检查引用上角标、斜体、上下标、英文数字字体和局部加粗，因为这些局部格式最容易丢失。正文引用应把完整方括号及内部编号设为上角标，例如 `[1]`、`[3-4]`；相邻的逗号、顿号、句号等正文标点不随引用上标。
12. 保存后重新运行结构审计，并用文档 Skill 将全文渲染为 PDF 和逐页图片。逐页查看文字溢出、孤行孤页、孤立标题、近空白页、表格断裂、图表错位、页码异常和字体不一致。
13. 交付时说明修改了哪些类别、未修改哪些内容、采用了哪份规范、备份位置、结构检查结果和视觉检查结果。

## 不得省略的安全规则

- 不因排版规范化改写论文内容、改变事实、数据、公式、引用编号或章节含义。
- 不凭经验擅自补充学校未提供的封面字段、签字页或声明文本。
- 不把视觉上相似的字体当作已确认字体；同时检查样式继承、主题字体和 run 级覆盖。
- 不删除分节符、域、隐藏书签或交叉引用来“简化”文档。
- 不以一次自动脚本输出代替全文逐页视觉复核。
- 没有本届权威规范时，不得声称“完全符合学校要求”。

## 资源使用

- 完整阅读 `references/论文格式审查清单.md`，按学校材料选取适用规则。
- 运行 `scripts/audit_thesis_format.py <论文.docx> --output <审计结果.json>` 获取结构证据。
- 用户或学校要求正文数字引用使用上角标时，运行 `scripts/fix_citation_superscripts.py <论文.docx> --in-place`；脚本只修改参考文献章节之前的方括号数字引用，并在系统临时目录创建备份。
- 审计脚本的“未引用文献”可能包含背景阅读材料；必须结合正文和学校要求人工判断，不能自动删除。
