# 中文论文 AIGC 降重

依据检测报告对疑似段落进行结构性改写，在降低模板化表达的同时保护学术事实和文档格式。检测结果只是概率信号，不是对文本来源或作者身份的证明。

## 前置材料：先向用户说明

开始精准降重前，必须请用户提供以下两项材料：

1. **需要修改的权威论文 DOCX**：应是与检测时相同的版本；若存在多个版本，先确认唯一主文件。
2. **AIGC 检测报告**：优先使用能看到段落级疑似度和疑似文本的完整报告。

推荐报告形式为 PaperPass 等平台导出的离线 HTML 报告，也可使用包含完整检测明细的 Word、PDF 或网页文件。理想报告应包含：

- 每个段落或句子的疑似度分数；
- 风险等级或颜色标记；
- 被判定为疑似的原文片段；
- 该片段的完整段落上下文；
- 章节标题、页码或其他定位信息。

如果用户只提供总疑似度、结果截图或不含具体段落的摘要页，不能据此准确定位并直接修改论文。应说明需要导出“详细报告、全文明细或逐段疑似度报告”后再继续。若报告中的文字与当前论文版本明显不一致，也应停止写回并请用户提供对应版本；不要用模糊匹配猜测修改位置。

## 必须配合的能力

所有 Word 文档操作必须同时使用可用的 DOCX/文档编辑 Skill，并遵守其备份、渲染和视觉验证流程。

## 工作流程

1. 确认权威论文 DOCX 和详细 AIGC 报告均已提供，并核对二者版本一致。若用户已经指定唯一主文件，只更新该文件。
2. 修改前将 DOCX 备份到操作系统临时目录。除非用户要求，不要把备份、审计报告或 QA 文件放在论文目录旁边。
3. 检查报告的数据来源。对于 PaperPass 离线报告，优先读取 `htmls/js/simplesentenceresult_ai.js`；页面中的红色文字通常由含分数的 JavaScript 数据生成，不一定是 HTML 内的红色 span。
4. 运行 `scripts/analyze_paperpass_report.py` 提取疑似文本并映射到 DOCX 段落。逐项审核映射结果；置信度低于 0.90 时必须人工核查。除非报告明确标记且用户要求，不处理封面、目录、页眉、题注、表格和参考文献。
5. 完整阅读 `references/rewrite-rules.md` 后再起草。以完整段落为单位理解和改写，不能只替换标红词语。
6. 构造包含 `paragraph_index`、`original_text` 和 `new_text` 的 JSON 列表。除非用户明确允许且不会影响格式，否则保持段落数量不变。
7. 运行 `scripts/apply_docx_rewrites.py`。脚本会验证原文、受保护数字与技术标记，创建临时备份，保留段落属性和样式，并更新唯一权威 DOCX。
8. 比较修改前后的段落、表格、图片、标题、分节和页数，调查所有非预期变化。
9. 使用文档 Skill 将完整 DOCX 渲染为 PDF 和逐页图片，检查每一页的文字溢出、孤立标题、间距变化、表格断裂、图片移动、空白页和字体不一致。
10. 交付时说明修改范围、涉及章节、受保护事实、备份位置和视觉检查结果。明确说明：只有将修改稿重新上传检测平台，才能得到新的检测分数。

## 改写约束

- 保留所有数量、单位、指标值、数据集划分、随机种子、模型名、API 名、路径、配置键、公式、图表引用和参考文献编号。
- 保持原有结论强度，不能把观察写成证明、把相关性写成因果关系，或把有限实验扩展为普遍结论。
- 不得虚构功能、实验、来源、数据、实现细节、创新点或局限性。
- 技术术语没有准确替代词时必须保留。通过改变句子组织和论述顺序减少重复，不得牺牲术语准确性。
- 保持段落在章节中的功能以及与上下段的逻辑关系。
- 使用自然、具体、克制的学术中文，减少公式化过渡、机械四段式排比、连续重复“本文……”和口语化填充。
- 中文论文中新插入的 run 优先继承段落样式；保存后检查实际生效字体。常见要求为中文宋体、英文与数字 Times New Roman，但必须以论文模板为准。
- 不承诺一定降低到某个分数。不同检测平台和不同提交批次可能给出不同结果。

## 映射与置信度规则

- 优先使用规范化后的精确匹配，再考虑模糊匹配。
- 把报告完整上下文映射到 DOCX 完整段落时，只消除空白差异；不能忽略数字、具有语义的标点或技术符号。
- 只有候选位置唯一且置信度不低于 0.90 时，才允许自动接受映射。
- 报告块跨越多个 DOCX 段落时，分别映射各段并保持顺序。
- 出现多个合理候选、报告对应旧版本或源段落已经发生实质变化时，停止修改并解决版本问题。

## 资源使用

- 使用 `scripts/analyze_paperpass_report.py` 提取报告内容并映射段落。
- 只有逐项人工审核改写方案后，才能使用 `scripts/apply_docx_rewrites.py` 写回。
- 完整阅读 `references/rewrite-rules.md`，执行其中的降重逻辑、事实保护、验证清单和示例规则。
