# 自创 Skills

- [arxiv-search](./arxiv-search)：功能：检索 arXiv 论文；解决：预印本搜索与筛选不便；场景：按主题、分类或日期找论文；条件：需 Python 和网络。
- [douyin-video-downloader](./douyin-video-downloader)：功能：下载并归档抖音公开视频；解决：视频和元数据难以完整保存；场景：备份、整理或分析抖音链接；条件：需 Python、网络和公开链接。
- [gpt-image](./gpt-image)：功能：用 OpenAI Images API 生成、编辑和局部重绘图片；解决：图像创作与修改流程分散；场景：海报、中文排版、UI 图和修图；条件：需 `OPENAI_API_KEY`。
- [html-ppt-build](./html-ppt-build)：功能：以 HTML 制作并导出技术 PPT；解决：中文密集型页面不清晰、难迭代；场景：方案、答辩和架构演示；条件：需 Python 与 Chrome 或 Edge。
- [local-operator-memory](./local-operator-memory)：功能：记录并复用本机运维经验；解决：环境配置与故障排查重复进行；场景：项目、Git、代理和服务操作；条件：需本机 Python 环境。
- [mineru-to-markdown](./mineru-to-markdown)：功能：将文件转换为 Markdown；解决：文档内容难提取和结构化；场景：解析 PDF、Office、图片、网页等资料；条件：轻量模式无需 Key，精确模式需 `MINERU_API_TOKEN`。
- [ppt-technical-redesign](./ppt-technical-redesign)：功能：重构技术 PPT 页面；解决：普通页面逻辑弱、信息密度低；场景：项目汇报、技术路线和架构页；条件：需提供原始 PPT 或页面文案。
- [semantic-scholar-search](./semantic-scholar-search)：功能：检索 Semantic Scholar 学术数据；解决：论文、作者和引用关系查询分散；场景：文献调研与引用分析；条件：需 Python 和网络，可配置 `S2_API_KEY`。
- [temporary-public-file-links](./temporary-public-file-links)：功能：将本地文件临时公开为链接；解决：产物无法通过附件查看；场景：分享截图、报告、日志和媒体文件；条件：需网络，且文件不得包含敏感信息。
- [video-narration-tts](./video-narration-tts)：功能：生成并合成中文视频配音；解决：旁白与画面不同步；场景：给视频添加、替换或优化解说；条件：需阿里云 MaaS Key、服务地址和 FFmpeg。
- [xiaohongshu-note-downloader](./xiaohongshu-note-downloader)：功能：下载并归档小红书公开笔记；解决：笔记图片、视频和元数据难保存；场景：备份、整理或分析小红书链接；条件：需 Python、网络和公开链接。
