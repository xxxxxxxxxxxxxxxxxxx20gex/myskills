# 中文毕业论文格式审查清单

## 一、使用原则

本清单用于建立审查框架，不替代学校本届正式模板。遇到冲突时，以本届学校或学院正式文件为准。审查报告中的每一项应标记为“符合”“不符合”“待确认”或“不适用”，并记录证据位置。

## 二、规范材料

- 主论文是否唯一，文件版本是否与用户确认一致。
- 是否取得本届学校模板、学院细则、提交通知、答辩要求、封面、声明页和签字页。
- 规范材料是否明确适用于完整论文，而非优秀论文汇编、摘要集或评优材料。
- 不同材料有冲突时，是否记录来源、日期、适用对象和采用理由。

### 大连民族大学已知材料的适用边界

已知《大连民族大学优秀毕业设计（论文）撰写规范》包含 A4、上边距 3.5 cm、下边距 2.5 cm、左边距 2.5 cm、右边距 2.5 cm 等版面要求，同时包含约 3000 字、五号宋体、1.25 倍行距等优秀论文汇编要求。该附件可作为部分版面证据，但不得直接作为完整毕业论文全文格式的唯一依据。

## 三、页面、分节与页码

- 纸张尺寸、方向、装订线及上下左右页边距。
- 封面、摘要、目录、正文、参考文献、致谢和附录的分节是否合理。
- 首页不同、奇偶页不同以及节间页眉页脚链接是否符合模板。
- 页码起始页、编号格式、罗马数字与阿拉伯数字切换、位置及字体。
- 页眉内容、分隔线、距边界距离和首页是否显示。
- 是否存在意外空白页、近空白页、孤行、孤页或孤立标题。

## 四、字体、字号与段落

- 中文通常采用宋体，英文、数字及拉丁符号通常采用 Times New Roman；最终以学校模板为准。
- 正文常见为小四号（12 pt），标题常用黑体并按级别区分字号，图题、表题、表内文字和参考文献常见为五号（10.5 pt）。这些是通用核查起点，不是无条件硬性值。
- 检查样式定义、基于样式、主题字体和 run 级直接格式，不能只抽查视觉效果。
- 正文对齐、首行缩进、左右缩进、行距、段前段后是否统一。
- 常见完整论文正文可能使用固定值 22 磅和首行缩进 2 字符；必须先由学校模板确认。
- 一级、二级、三级标题的编号、字体、字号、加粗、对齐、段前段后和分页控制是否一致。
- 标点挤压、英文断词、中西文空格、全角半角和数字单位之间的空格是否一致。

## 五、封面、摘要与关键词

- 封面内容、顺序、对齐和空格是否与原始模板一致。
- 题名是否在正文、中文摘要、英文摘要和声明页中一致。
- 中英文摘要的标题、正文、缩进、行距和分页是否符合要求。
- 关键词数量、分隔符、标签字体以及中英文对应关系。

## 六、目录

- 目录是否由域生成，标题样式映射是否正确，级别是否完整。
- 目录文字、缩进、制表位、点引导线和页码对齐。
- 更新域并保存后，目录缓存页码是否与正文一致。
- 不仅检查导出的 PDF；同时检查 DOCX 内目录域是否可继续更新。

## 七、图、表与公式

- 图题位于图下、表题位于表上，位置以学校模板为准。
- 图表按章或全文编号时是否连续，正文交叉引用是否存在且一致。
- 题注不得误用正文样式；字体、字号、居中、段前段后应统一。
- 图片是否清晰、无拉伸、无裁切、无文字溢出，并与正文留白合理。
- 表格是否符合三线表或学校指定样式；表头是否重复、跨页是否合理、单元格字体字号是否统一。
- 公式字体、编号、对齐和正文引用是否一致。

## 八、正文引用

- 本 Skill 当前适用论文的正文方括号数字引用统一使用上角标；检查完整左方括号、编号、连接符和右方括号是否均为上角标，例如 `[1]`、`[3-4]`。
- 引用后的逗号、顿号、分号和句号属于正文标点，保持普通基线格式；并列引用如 `[16]、[20-21]` 应分别上标两个方括号引用，顿号不上标。
- 参考文献章节的条目编号（如 `[1]`）不设为上角标，保持参考文献段落的普通基线格式。
- 连续编号与并列编号的连接符、逗号和顺序是否一致。
- 正文引用是否存在对应参考文献，引用范围是否越界。
- 改写或替换整段文字后，应专门复查引用 run 的上角标属性，并确认没有误把相邻正文或标点设为上标。

## 九、参考文献

- 连续编号、正文出现顺序、悬挂缩进、行距和字体字号。
- 按学校指定版本执行 GB/T 7714，统一作者、题名、文献类型标识、出版项、年份、卷期、页码、DOI 或 URL 和访问日期。
- 中文与外文文献的标点、作者大小写、期号前导零等细节是否一致。
- 区分“排版正确”和“来源真实”；后者需要查验数据库、DOI 或原始出版信息。
- 不得因脚本提示“未引用”就自动删除文献。

## 十、视觉交付检查

- 全文渲染，不只抽查前几页。
- 检查页面总数和修改前后结构计数是否有意外变化。
- 逐页检查封面、目录、章节首页、图表密集页、参考文献和附录。
- 记录无法自动确认的签字、盖章、装订顺序和学校系统提交要求。
